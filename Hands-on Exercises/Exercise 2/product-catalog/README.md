# Exercise 2 solution

Run `npm install`, then `npm run invoice` for Question 1.
Run `npm test` to check the calculator.
Run `npm run dev` for the React catalog and open the URL Vite prints.
Run `npm run build` and `npm run preview` to preview the production build.
Requires Node.js 20.19+ or 22.12+.

Question 1: src/products.js, calculator.js, invoice.js.
Question 2: src/ProductCard.jsx, src/App.jsx, src/main.jsx, src/styles.css.
The sample order subtotal is Rs. 94,100, discount Rs. 9,410, final Rs. 84,690.
The second invoice demonstrates no discount at exactly Rs. 50,000.
