# Exercise 2 - Beginner-Friendly Version

This version intentionally uses simple JavaScript and React code so that each
required concept can be understood separately.

## Question 1

Run:

```bash
npm run invoice
```

Important files:
- `src/products.js` - product array
- `calculator.js` - available products, order calculation, invoice functions
- `invoice.js` - sample cart and function calls

Expected totals for the sample cart:
- Subtotal: Rs. 94100
- Discount: Rs. 9410
- Final Total: Rs. 84690

## Question 2

Run:

```bash
npm install
npm run dev
```

Important files:
- `src/ProductCard.jsx` - one product card
- `src/App.jsx` - product list, `map()`, state and Add to Cart
- `src/styles.css` - responsive grid styling

The Mouse has stock 0, so its Add to Cart button is disabled.

`calculator.test.js` is optional and is not required by the DigiSkills exercise.
